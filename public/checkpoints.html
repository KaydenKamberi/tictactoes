CP02-accounts

The tag: CP02-accounts

GitHub Link: View Code for CP02

What I built: I implemented a full user authentication system. This includes backend Express routes for registration, login, and logout, and a frontend that communicates with these routes using the Fetch API. User data is persisted in a local JSON file.

What was hard: The most difficult part was managing the file structure. I accidentally created duplicate folders and files, which made the server and .gitignore act unpredictably until I flattened the tree back to the root.

What I'd do differently: I would stick strictly to the required file structure from the very beginning to avoid having to move files and fix broken paths later.

AI usage note: AI helped me write the session logic and fetch calls, but I had to manually troubleshoot why my 'View Checkpoints' button wasn't disappearing because the ID wasn't defined correctly in my script.

A/B testing note: I tried hiding only the 3x3 board div, but switched to hiding the entire game section so the "Game" header wouldn't stay visible to logged-out users.

CP01-world

The tag: CP01-world

GitHub Link: View Code for CP01

What I built: I set up the basic Node.js and Express environment. I created the public folder for static files and established the initial server.js entry point to serve the index.html file.

What was hard: Learning how Git tracks (and ignores) files was new to me, especially setting up the .gitignore for the first time to keep the node_modules folder out of the repo.

What I'd do differently: I would have read the project brief more carefully regarding naming conventions like 'main.js' versus 'script.js' before I started coding.

AI usage note: I used AI to generate the initial Express boilerplate, but I had to fix the port configuration to make sure it worked on my specific development environment.

A/B testing note: I compared using a simple 'Hello World' text response versus sending a full HTML file; I chose the HTML file because it felt like a more realistic starting point for a web app.
