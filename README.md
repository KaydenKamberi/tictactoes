# Tic Tac Toe AI

A web app for playing Tic Tac Toe against an AI opponent.

## Setup
1. Clone the repository.
2. Install dependencies: `npm install`
3. Create a `.env` file based on `.env.example`.
4. Run the server: `npm start`

## Features
- Sign up, log in, and log out
- Play against another human or an AI
- Leaderboard and stats
- Checkpoints page

## Reflection
This project was built to learn spec-driven development, AI-assisted coding, and GitHub fundamentals.
